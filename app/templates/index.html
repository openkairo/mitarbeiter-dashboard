    Die Zugangsdaten liegen auf dem Server in der .env und wurden dort eingerichtet — hier lassen sie sich ändern, ohne sich am Server anzumelden. Ein leeres Feld bedeutet: es gilt wieder der Wert aus der .env. Gespeicherte Geheimnisse werden nie zurück angezeigt, nur ihre letzten vier Zeichen.

    ✉️ Postfächer

    Beliebig viele Postfächer, auch bei verschiedenen Anbietern und auf verschiedenen Wegen: Jedes trägt selbst, ob es über die Anbieter-API oder per IMAP gelesen wird. Die Karte „Posteingang“ führt sie zusammen und zeigt bei jeder Zeile, aus welchem Postfach sie kommt. Gelesen wird nur; nichts wird als gelesen markiert. Löschen entfernt auch den hinterlegten Zugang — ein Postfach, das keiner mehr braucht, soll keine Zugangsdaten zurücklassen.

    🤖 Zugang für eine KI

    Über diese Adresse kann Claude das Dashboard lesen und bedienen — Karten abrufen, Posten abhaken, Notizen schreiben, Verbindungen prüfen.

    —

    Wer diese Adresse hat, kann alles — auch Zugangsdaten ändern, und zwar ohne Passwort. Nicht per Chat oder E-Mail weitergeben. Ist sie doch einmal abhandengekommen: neuen Token auf dem Server erzeugen (openssl rand -hex 24), in der .env unter MCP_TOKEN eintragen, Container neu starten.
